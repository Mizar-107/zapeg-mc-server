# ZapeG görsel ön-ayarı (shaders açık başlasın)

ATM9 zaten Oculus + Embeddium + Complementary shader paketleriyle geliyor — kapalı duruyorlar. Bu iki küçük dosya ilk açılışta shader'ı **açık** getirir.

**Kurulum (Yol A oyuncuları):** `zapeg-client-defaults.zip`'i profil klasörüne aç (CurseForge → profil → ⋮ → Open Folder), üzerine yazmayı onayla. İlk açılıştan ÖNCE yapılırsa options.txt de temiz uygulanır.

- Shader aç/kapa tuşu: **K**
- Kasarsa: Video Settings → Shader Packs → **MakeUp-UltraFast** seç (o da pakette var)
- "Shader seçili ama açılmıyor" dersen: `shaderpacks/` klasöründeki gerçek dosya adına bak, `config/oculus.properties` içindeki `shaderPack=` satırını eşitle

Yol B oyuncularının bir şey yapması gerekmez — instance zip bunları içinde getirir.
