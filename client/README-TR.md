# Başlık ekranı logosu (client, kozmetik)

Yeni `ZapeG-Kurulum-Yamasi` ve `ZapeG-Offline` paketleri bu logoyu otomatik içerir. Aşağıdaki adımlar yalnızca eski/mevcut bir profili elle düzeltmek içindir.

Sunucu için gerekli değildir; sadece stok ATM9 yazısı yerine **ZAPEG / ATM9+** logosunu gösterir:

1. CurseForge App → profil → **⋮ → Open Folder**
2. Bu repodaki `client/packmenu/` klasörünün içeriğini, instance'taki `packmenu/` klasörünün üstüne kopyala (`resources/assets/packmenu/textures/gui/logo.png` dosyasının üzerine yazacak).
3. Oyunu yeniden başlat.

Not: CurseForge App pack'i güncellerse orijinal logo geri gelebilir — aynı kopyalamayı tekrarla. Sunucu listesindeki ikon (server-icon) bundan bağımsız, o sunucudan otomatik gelir.
